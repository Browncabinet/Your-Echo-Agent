## Add `glama.json` for Glama.ai MCP directory

Create a `glama.json` at the repo root so Glama.ai can index this project's MCP server.

```json
{
  "$schema": "https://glama.ai/mcp/schemas/server.json",
  "maintainers": ["<your-github-username>"]
}
```

## One thing I need from you

What's the **GitHub username** (or usernames) of the maintainer(s) to list? Glama uses this to verify ownership of the listing.
